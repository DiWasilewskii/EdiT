# EdiT — ІКТ для дітей 2–9 класів

**E**ducation • **D**igital • **I**nnovation • **T**echnology

## Як відкрити
Двічі клацніть `index.html` — сайт відкриється в браузері. Інтернет потрібен лише для шрифтів.
Щоб опублікувати, завантажте всю папку на будь-який хостинг (наприклад, GitHub Pages).

## Як додати тему
Усі теми лежать в одному файлі — **`js/topics.js`**. Інструкція — на початку цього файлу.

1. Скопіюйте приклад теми.
2. Вставте в потрібний масив (`ТЕМИ_КЛАСІВ` або `ТЕМИ_ПОЗА_ПРОГРАМОЮ`).
3. Змініть клас/вік, номер, назву, опис, пояснення, кроки й питання.
4. Збережіть і оновіть сторінку.

## Файли
| Файл | Що всередині |
|---|---|
| `index.html` | каркас сторінки |
| `js/topics.js` | **теми** — редагувати тут |
| `js/app.js` | логіка: сторінки, меню, тести, прогрес |
| `css/style.css` | кольори, шрифти, вигляд |
