# Іконки

Іконки з відкритого набору **Tabler Icons** (https://tabler.io/icons), версія 3.53.0,
ліцензія MIT — їх можна вільно використовувати на сайті.
Колір лінії змінено на «Джунглі» (#1F3A2B), фон-кружечок додає css/style.css.

Щоб замінити іконку (наприклад, на згенеровану у Figma), покладіть новий SVG
з тією самою назвою файлу.

| Файл | Де використовується |
|---|---|
| t3-01 … t3-13 | теми 3 класу (номер теми) |
| t4-01 … t4-15 | теми 4 класу (номер теми) |
| t5-01 … t5-21 | теми 5 класу (номер теми) |
| t6-01 … t6-15 | теми 6 класу (номер теми) |
| t7-01 … t7-13 | теми 7 класу (номер теми) |
| t8-01 … t8-16 | теми 8 класу (номер теми) |
| t9-01 … t9-15 | теми 9 класу (номер теми) |
| t2-01 … t2-14 | теми 2 класу (номер теми) |
| p-01, p-02 | теми «Поза програмою» |
| cat-* | категорії «Поза програмою» |
| ui-* | кнопки й заголовки блоків |
